**CSS Grid** — система раскладки для создания строк и столбцов. Она подходит для галерей, карточек, основных областей страницы и макетов, где важно управлять двумя направлениями одновременно.

# Grid-контейнер
```html
<section class="gallery">
  <article class="gallery__item">1</article>
  <article class="gallery__item">2</article>
  <article class="gallery__item">3</article>
</section>
```

```css
.gallery {
  display: grid;
}
```

<div className='example'>
<section style={{ display: 'grid', gridTemplateColumns: 'repeat(3, 1fr)', gap: '10px' }}>
  <article style={{ padding: '18px', backgroundColor: '#dbeafe' }}>1</article>
  <article style={{ padding: '18px', backgroundColor: '#bfdbfe' }}>2</article>
  <article style={{ padding: '18px', backgroundColor: '#93c5fd' }}>3</article>
</section>
</div>

`.gallery` становится grid-контейнером, а его непосредственные дочерние элементы — grid-элементами.

# Столбцы grid-template-columns
Три столбца одинаковой ширины:
```css
.gallery {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
}
```

Единица `fr` означает долю свободного места.

Сокращённая запись:
```css
.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}
```

Столбцы разной ширины:
```css
.layout {
  display: grid;
  grid-template-columns: 240px 1fr;
}
```

<div className='example'>
<div style={{ display: 'grid', gridTemplateColumns: '140px 1fr', gap: '12px' }}>
  <aside style={{ padding: '12px', backgroundColor: '#e2e8f0' }}>Меню</aside>
  <main style={{ padding: '12px', backgroundColor: '#f8fafc' }}>Основное содержимое</main>
</div>
</div>

Первый столбец фиксированный, второй занимает оставшееся место.

# Строки grid-template-rows
```css
.layout {
  display: grid;
  grid-template-rows: auto 1fr auto;
  min-height: 100dvh;
}
```

Верхняя и нижняя строки зависят от содержимого, средняя занимает свободное место.

Во многих карточках строки создаются автоматически, поэтому `grid-template-rows` требуется не всегда.

# Расстояние gap
```css
.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
}
```

Можно разделить направления:
```css
.gallery {
  row-gap: 32px;
  column-gap: 24px;
}
```

# Адаптивные столбцы без медиазапроса

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 24px;
}
```

Разбор:
- `minmax(240px, 1fr)` — столбец не уже `240px`, но может расти;
- `auto-fit` — браузер размещает столько столбцов, сколько помещается;
- `repeat()` повторяет описание столбца.

Если контейнер становится узким, карточки переходят на новые строки.

`auto-fill` и `auto-fit` похожи, но по-разному обращаются с пустыми возможными колонками. Для обычной адаптивной галереи чаще удобен `auto-fit`.

# Размещение элемента по линиям
Grid-линии нумеруются от `1`.

```css
.featured-card {
  grid-column: 1 / 3;
}
```

Элемент занимает пространство от первой до третьей линии, то есть два столбца.

С помощью `span`:
```css
.featured-card {
  grid-column: span 2;
}
```

По строкам:
```css
.tall-card {
  grid-row: span 2;
}
```

На узком экране такие правила нужно проверять: элемент может занимать больше колонок, чем доступно.

# Именованные области

```css
.page {
  display: grid;
  grid-template-columns: 220px 1fr;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}

.page__header {
  grid-area: header;
}

.page__sidebar {
  grid-area: sidebar;
}

.page__main {
  grid-area: main;
}

.page__footer {
  grid-area: footer;
}
```

Именованные области делают крупную структуру наглядной. Каждая строка шаблона должна иметь одинаковое количество ячеек.

Для простых рядов карточек области не нужны.

# Выравнивание элементов
## justify-items
Выравнивает содержимое ячеек по горизонтальному направлению строки.

```css
.gallery {
  justify-items: center;
}
```

## align-items
Выравнивает по вертикальному направлению внутри ячейки.

```css
.gallery {
  align-items: center;
}
```

## place-items
Сокращает оба свойства.

```css
.icon-grid {
  display: grid;
  place-items: center;
}
```

## justify-content и align-content

Распределяют всю grid-сетку внутри контейнера, если сетка меньше доступного места.

# Выравнивание отдельного элемента
```css
.card--special {
  justify-self: center;
  align-self: start;
}
```

Сокращение:
```css
.card--special {
  place-self: start center;
}
```

# Неявная сетка
Если элементов больше, чем описано в шаблоне, браузер создаёт дополнительные строки или столбцы.

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: minmax(160px, auto);
}
```

`grid-auto-rows` задаёт размер автоматически созданных строк.

# Полезное min-width: 0
Иногда длинный текст или ссылка не позволяет grid-элементу сжаться и вызывает переполнение.

```css
.grid-item {
  min-width: 0;
}
```

Это не нужно добавлять всем элементам заранее, но полезно помнить при неожиданной горизонтальной прокрутке.

# Grid или Flexbox
Grid удобнее, если:
- нужны строки и столбцы одновременно;
- элементы должны совпадать по колонкам;
- создаётся галерея;
- есть крупные области страницы.

Flexbox удобнее, если:
- элементы идут одной строкой или столбцом;
- нужно распределить пространство в одном направлении;
- выравниваются иконка и подпись;
- создаётся меню или панель кнопок.

Пример совместного использования:

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 24px;
}

.card__actions {
  display: flex;
  gap: 12px;
}
```
