# Что такое веб-страница
**Веб-страница** — это документ, который открывается в браузере.
**Браузер** — это программа, которая умеет читать код страницы и показывать его человеку в понятном виде.

Примеры браузеров:
* Google Chrome;
* Яндекс Браузер;
* Safari;
* Mozilla Firefox;
* Microsoft Edge.

Когда мы открываем сайт, браузер получает файлы сайта, читает их и показывает страницу на экране.

Обычно у простой веб-страницы есть два главных файла:
- index.html - отвечает за содержимое страницы.
- style.css - отвечает за внешний вид страницы.

# Что такое HTML
**HTML** (HyperText Markup Language) — это язык гипертекстовой разметки страницы, который отвечает за структуру и содержание страницы. Он не программирует, а описывает, как должна выглядеть страница в браузере: где заголовок, где картинка, где текст, куда ведёт ссылка и так далее.

Каждый такой элемент в HTML называется **тегом**. Теги определяют назначение элемента и его наполнение. В данном курсе мы познакомимся с основным набором тегов, которого будет достаточно для верстки любой веб-страницы. 

Рассмотрим пример простейшей HTML-страницы:
``` html
 <!DOCTYPE html>
<html>
  <head>
    <title>Мой первый сайт</title>
  </head>
  <body>
    <h1>Привет, мир!</h1>
    <p>Это моя первая веб-страница на HTML.</p>
  </body>
</html>
```
(и то как это выглядит на сайте без стилей)

Пока это выглядит давольно просто и скучно, а чтобы сайт выглядел красиво и реагировал на действия пользователя, HTML используется вместе с другими технологиями:
- CSS — оформляет внешний вид: цвета, отступы, шрифты.
- JavaScript — добавляет интерактив: анимации, кнопки, всплывающие окна и логику поведения страницы.

Взгляните внимательно на страницу, на которой вы сейчас находитесь. Вся она вне зависимости от внешнего вида описана с помощью HTML. Вы можете сами попробовать открыть разметку этой страницы с помощью комбинации `Ctrl + U` или `Command + Option + U` (на macOS).

Не пугайтесь всего того, что здесь есть. Со временем для вас это перестанет быть «магией», и вы с легкостью будете ориентироваться в HTML-разметке.

С помощью HTML можно верстать любые страницы, которые открываются в браузере. Это могут быть:
- сайты и лендинги — от простых визиток до огромных порталов;
- письма для рассылок — да, они тоже пишутся на HTML (но с оговорками);
- интерфейсы в админках и CMS — форма входа, таблица с заказами, карточка товара;
- документация, инструкции и статьи — если они отображаются прямо в браузере;
- шаблоны для генерации PDF или отчётов — HTML используется как основа.

А ещё HTML нужен, чтобы делать прототипы, встраивать виджеты, подключать аналитику и даже делать интерфейсы для интернет вещей (IoT). В общем, всё, что хоть как-то связано с вебом, — всё начинается с HTML.

Еще одним важным понятием является **«Дерево элементов» (или DOM-дерево)** — это внутренняя структура, которую браузер строит, когда читает HTML-код. Она показывает, какие элементы есть на странице и как они связаны между собой — кто является «родителем», «дочерним элементом» и т.д.

Браузер не просто видит текст с тегами, а превращает его в **иерархию объектов**, где каждый тег — **узел дерева**.

Визуально этот код из HTML:
```html
<body>
  <h1>Привет</h1>
  <p>Это пример</p>
</body>
```

Будет выглядеть так:
```javascript
html
 └── body
      ├── h1
      │    └── "Привет"
      └── p
           └── "Это пример"
```

Как мы видим главным (корневым) элементом является `<html>`, затем у него есть ветви `<head>`  и `<body>`. Уже внутри них могут присутствовать **дочерние элементы**: заголовки, абзацы, ссылки и т.д.

# Что такое CSS
**CSS** (Cascading Style Sheets) — это язык стилей, с помощью которого оформляют веб-страницы. Он определяет, как именно должны отображаться HTML-элементы: их цвет, размеры, расположение, шрифты, анимацию и так далее.

Получается, что HTML создает элементы страницы, CSS оформляет эти элементы.
