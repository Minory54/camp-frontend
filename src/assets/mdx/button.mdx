## О компоненте

`Button` отображает кнопку с пиксельным оформлением. JSX ниже показывает сам компонент, а блок кода — пример его использования.

## Цвета

<Button color="blue">Синяя кнопка</Button>

<Button color="green">Зелёная кнопка</Button>

```tsx
<Button color="blue">Синяя кнопка</Button>
<Button color="green">Зелёная кнопка</Button>
```

## Размер

Для компактного варианта передай свойство `small`.

<Button color="yellow" small>Компактная кнопка</Button>

```tsx
<Button color="yellow" small>Компактная кнопка</Button>
```

## Недоступное состояние

<Button disabled>Недоступно</Button>

```tsx
<Button disabled>Недоступно</Button>
```
